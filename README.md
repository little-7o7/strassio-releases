# Strassio — установщики

Strassio — плагин для CorelDRAW (X7 и новее, Windows), который превращает линии и фигуры в шаблоны страз.
Каждая страза — обычный круг нужного диаметра, дальше вы работаете с ним как привыкли.

Здесь лежат только установщики. Сайт: https://strassio.vercel.app

## Как установить

1. Скачайте последнюю версию: **https://strassio.vercel.app/download**
   (все версии — в разделе [Releases](https://github.com/little-7o7/strassio-releases/releases)).
2. Закройте CorelDRAW и запустите `Strassio-Setup-<версия>.exe`. Он сам найдёт все CorelDRAW на компьютере.
3. Откройте CorelDRAW и нажмите кнопку-камень на панели **Strassio**.

Windows может предупредить «Неизвестный издатель» — нажмите «Подробнее» → «Выполнить в любом случае».

Новая версия ставится поверх прежней: настройки, таблица камней и лицензия сохраняются.
Плагин сам сообщает, когда выходит новая версия.

# Strassio — installers

Strassio is a CorelDRAW add-on (X7 and newer, Windows) that turns lines and shapes into rhinestone templates.
Every stone is a plain circle of the right diameter. This repository holds installers only.

1. Download the latest version: **https://strassio.vercel.app/download**
2. Close CorelDRAW and run `Strassio-Setup-<version>.exe`.
3. Open CorelDRAW and click the stone button on the **Strassio** toolbar.
